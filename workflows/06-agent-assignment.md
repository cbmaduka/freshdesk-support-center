# Agent Assignment Workflow

## Purpose

This workflow explains how customer enquiries are assigned to the appropriate support agent or team.

---

# Assignment Process

1. Ticket received.
2. Category identified.
3. Priority assigned.
4. Appropriate support group selected.
5. Ticket assigned.
6. Agent accepts ownership.
7. Resolution begins.

---

# Assignment Rules

Tickets may be assigned based on:

- Category
- Product
- Customer type
- Agent availability
- Workload
- Priority level

---

# Assignment Goals

- Balanced workloads
- Faster response times
- Improved expertise
- Better customer experience
