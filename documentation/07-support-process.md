# Customer Support Process

## Overview

The support process defines the standard lifecycle for every customer enquiry.

---

# Workflow

1. Customer submits request.
2. Ticket is created.
3. Ticket is categorised.
4. Priority is assigned.
5. Ticket is routed to the appropriate agent.
6. Agent investigates the issue.
7. Customer receives updates.
8. Issue is resolved.
9. Customer confirms resolution.
10. Ticket is closed.

---

# Success Measures

- Fast response times
- Accurate resolutions
- Positive customer feedback
- SLA compliance
