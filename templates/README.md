# Templates

This folder contains reusable templates developed for the Freshdesk Support Center implementation.

These templates promote consistent customer communication, efficient ticket handling, SLA compliance, and knowledge management across the support team.

Included templates:

- 01 Ticket Response Template
- 02 Customer Email Template
- 03 Ticket Macro Template
- 04 SLA Template
- 05 Knowledge Base Article Template
- 06 Customer Satisfaction Survey
- 07 Escalation Email Template
- 08 Ticket Closure Template

These resources are intended to standardize support operations and improve the overall customer experience.
